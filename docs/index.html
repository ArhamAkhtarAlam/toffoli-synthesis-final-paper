Every candidate is checked on all input rows. Hybrid keeps the candidate with the fewest gates among those no worse than the disjoint one in both gates and quantum cost. The paper's final step, choosing by CZ count after transpiling to an IBM device model, needs Qiskit and is not run here.

  Quantum cost of a Toffoli with k controls: 2k+1 − 3 (1 for X and CNOT). Circuits are out-of-place: inputs are kept, each output starts at |0⟩, and any helper qubit ends at |0⟩.
  Disjoint only: Algorithm 1's groups never overlap, so Theorems 1–2 prove the circuit correct. Hybrid also tries overlapping Reed–Muller covers, correct by the same parity rule (Theorem 2) and the merging lemma.
